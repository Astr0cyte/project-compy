# COMPY: a C compiler written in C

> This project is being completed by using Nora Sandler's book: Writing a C Compiler: https://norasandler.com/2017/11/29/Write-a-Compiler.html
- Despite advice to complete this project in a language other than C, I want to see how far I can go and what I can learn by writing this in C.
- I have nothing to lose and everything to gain, I might as well shoot for the moon! Worst case I get burnt and start learning a language like Rust to complete this project in.
- My aim is to use AI sparingly because I have no reason to: there is no due date, there are no marks, there is no one watching.
- There is only me and my personal growth.
