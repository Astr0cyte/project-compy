# COMPY: a C compiler written in C

> This project is being completed by using Nora Sandler's book: Writing a C Compiler: https://norasandler.com/2017/11/29/Write-a-Compiler.html
- Despite advice to complete this project in a language other than C, I want to see how far I can go and what I can learn by writing this in C.
- I have nothing to lose and everything to gain, so I'm shooting for the moon!
